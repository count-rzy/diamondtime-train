# Last Train v1.0.0-exp.1

**Experimental pre-release for Windows x64**

Last Train turns focused work into a railway journey through a pixel-art carriage, changing scenery and locally stored journey history. This experimental build brings together the local Windows edition and the railway, diary, atlas, statistics and audio features. Some features or workflows may still contain bugs. Back up your data before a major update.

## Highlights

- Set up journeys with work and rest periods, and review completed journeys and diary entries.
- Explore the animated carriage and scenery, interactive Railway Atlas and productivity statistics.
- Use the built-in radio, import supported music, and control locally generated train ambience.
- Choose Russian or English and adjust display, sound and atmosphere preferences.
- Create a full backup or export journeys and diary entries from Settings.

## Install on Windows

1. Download the Windows x64 portable ZIP attached to this pre-release.
2. Extract the **entire** ZIP to a writable folder. Do not run the app from inside the archive.
3. Keep **Start Last Train.exe**, **Stop Last Train.exe**, `_internal` and all other extracted files together.
4. Double-click **Start Last Train.exe**. The application opens in your browser and runs on this computer. Python, Node.js and VS Code are not required.
5. To stop the local server, double-click **Stop Last Train.exe**. Closing the browser tab alone does not necessarily stop it.

## Your data

The portable profile, including the SQLite database and backups, is stored under `%LOCALAPPDATA%\LastTrain`. The profile is separate from the program files and is preserved when you replace the application files during an update. Before a major update, create a backup in Settings and keep a copy somewhere safe.

Restoring from within Settings is not currently available. For recovery, use the existing source tool `restore.bat` from the project checkout while the app is stopped; follow its prompts and confirm only after reviewing the backup path. Do not replace a database while Last Train is running. The portable bundle does not include this source batch tool; portable in-app restoration requires a later release.

## Known limitations

- This is an experimental build; unexpected behavior and defects are possible.
- The app is intended for local use in a browser on the same Windows computer.
- The portable package is for Windows x64; it does not include a macOS or Linux application.
- Closing the browser does not stop the backend. Use **Stop Last Train.exe** when you want to stop the application.

## Troubleshooting

- **The app does not open:** confirm that you extracted the whole ZIP and kept the EXE files beside `_internal`. Try **Start Last Train.exe** again and follow any startup message.
- **The page is unavailable:** the local server may still be starting. If it does not recover, use **Stop Last Train.exe**, wait a few seconds, then start the app again.
- **The app will not stop:** run **Stop Last Train.exe** from the same extracted folder as the matching start executable. Avoid deleting or replacing program files while it is running.
- **You need to restore a backup:** use `restore.bat` from the source project while the app is stopped. This tool is not included in the portable bundle; do not copy a backup over a live database.
